## What was built
The credential in an `Authorization` header map no longer reaches the agent, whatever its scheme: `{"Authorization": "Basic <token>"}` comes back as `{"Authorization": "Basic [REDACTED]"}`. One name rule (compiled in, `isAuthorizationName`): a name counts when, stripped of invisible and control characters, trimmed and case-folded, it is `authorization` or ends in it after a character that is not an ASCII letter or digit (`Proxy-Authorization`, `HTTP_AUTHORIZATION`, `http.request.header.authorization`; not `authorizationMode`, `authorization_url`, `reauthorization`). It serves three forms: the object form in `sanitize.Payload` (every JSON object at any depth, the value of such a member when it is `<scheme> <token>` or a list of those), the quoted text form in `Redactor.Redact` (a quoted name, a colon and a quoted `<scheme> <token>` or first list item; `"` or `'`, escaped any number of times, line breaks allowed in a pretty-printed map), and the plain form of #180, which now also takes `HTTP_AUTHORIZATION: Basic …`. Scheme, token shape and minimum length are those of #180. It runs wherever #180 runs, before every cut (results, Langfuse error text, echoed names, confirmation body summary, audit line, last pass over a result's JSON text). What is sent to Langfuse and the confirmation state are unchanged.

## Decisions & deviations
- Work resumed from the failed attempt 1 patch (`196-partial.patch`), reviewed line by line, applied, and completed; the red/green and mutation checks it lacked were run here.
- The name rule trims space, tab, CR and LF around a name; the quoted form allows spaces, tabs and line breaks around the name, around the colon and after a list's bracket (a pretty-printed map matches), but between the scheme and the token only spaces and tabs, and a line break written as an escape (backslash n) is a documented limit. The plain form of #180 keeps spaces and tabs only.
- The quoted-form regex does not require the opening and closing quote to match (`"x'`); the plain and Bearer branches are the #180 ones with `(?:^|[^A-Za-z0-9])` instead of `\b` before `authorization`, so an underscore counts (decision 2 of the ticket).
- Quoted text form reads only a list's first item; the object form reads every string item (ticket decision 3, documented limit).
- One regular expression is kept (no hand-written scanner): RE2 is linear, shown by `TestRedactionTimeGrowsInProportionToTheInput` and the 112 KB token and 20000-member tests.
- `walk` always applies the object form (the member hook parameter was removed after review); `LineValue`, used only by the confirmation's body summary, therefore applies it too.
- Performance cost accepted and documented: text that names a header goes from 3.0 ms to 8.5 ms per 64 KiB through `Redact`; text with no header name is unchanged (0.14 ms).

## Learnings
- `git stash` in a worktree you share with reviewers or background jobs reverts every file under them; to compare with the base, copy the files to scratch and `git show <base>:<file>` over them, then copy back.
- A Python heredoc with `old = s[s.index(a):s.index(b)]` silently inserts at offset 0 when `b` occurs before `a` (the empty slice); assert on the slice before replacing.
- gosec G101 flags any identifier containing `token`/`cred` and any map literal of high-entropy strings in test files too: `//nolint:gosec // G101: …` on the declaration.
- The `server` package under `-race` needs the chunked run (see Verification) on this machine until #201 lands.
