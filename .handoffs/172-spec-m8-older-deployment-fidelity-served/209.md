## What was built
On a deployment that serves both read families (self-hosted 4.46.0 `dual`, Langfuse Cloud until 2026-11-16), an empty `get_trace_tree` now keeps today's hint and adds that the deployment's legacy reads may hold the trace if it was sent through the legacy ingestion API, naming `legacy_observationsV1_getMany` (with `traceId`) and `trace_get` through `execute_read`, each only when the resolved catalog offers it as a read operation (neither offered: today's hint). The routing is unchanged: the tree is read from Observations v2 only, an empty tree costs one request to that route and none to a legacy route. Every other deployment keeps its hint byte for byte. The tool description gains one static sentence, the same on every deployment: Observations v2 can lack observations sent through the legacy ingestion API, so an empty or short tree can be checked against the legacy observations list through `execute_read`. That sentence is the only cover for a tree that is short and not empty.

## Decisions & deviations
- The hint is built per call in `executor.v4TraceTreeEmptyHint` from the profile and the resolved catalog only (both fixed at startup), not stored at startup. The docs say "depends only on the profile and the resolved catalog, both fixed at startup". Reversible if a measurement ever asks for it (two map lookups per call).
- `offersRead` (Lookup + `IsRead`) is the predicate `traceTreeUnavailable` already used, extracted and reused in both places: no second rule.
- Hint wording uses "legacy reads" (the ticket's and the campaign's words) and states a possibility ("may hold"). The description sentence adds "(legacy_observationsV1_getMany with traceId)", an ID the description already names.
- `TraceTreeFailureOf` (export_test.go) still builds an `executor{catalog, profile}`; unaffected.
- A test client needs `RateLimit = 60_000` when it makes many calls (the default holds them: 28 s before the fix).

## Learnings
- `testOptions` clients use a low default rate limit: a test that makes more than a few calls through one session must set `RateLimit = 60_000` (as `connectLegacyTree` does).
- Check a test that "can never fail": a key-shaped value is redacted if echoed, so search the result for `[REDACTED]` as well as the value.
