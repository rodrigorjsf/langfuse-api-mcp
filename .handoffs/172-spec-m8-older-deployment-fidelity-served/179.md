## What was built
`execute_read` and `execute_write` now refuse, before any request, four things Langfuse used to be the first to check. A `page` below 1 (the catalog gives every `page` the minimum 1, so `describe_operation` shows "at least 1"). A parameter whose schema says `date-time` unless it is an RFC 3339 timestamp, strict shape, list items checked one by one; the refusal names the parameter and the format, never the value. A control or invisible character in a query parameter value, list items included, and in any decoded string or key of a metrics `query`, written as itself or as a JSON escape. The same kind of character in a path parameter, which is now refused instead of passed on (campaign finding M7), a Folder name on the allow-list included. `orderBy` is untouched. Only a `filter` (a JSON text Langfuse parses) may hold tab, line feed and carriage return.

## Decisions & deviations
- `page` minimum is set at catalog load, like the list `limit`, not in `Request`. Consequence: `describe_operation` reports `minimum: 1` for `page` (two golden literals in `describe_test.go` updated) and the existing `TestExecuteReadRefusesAValueOutsideASpecGivenBoundOfTheCatalogWithoutCallingLangfuse` stops skipping and now covers `page` on every read operation. `TestAParameterWithoutBoundsCarriesNone` used `page` as its example of an unbounded parameter; it uses `userId` now.
- Source of the `page` and `date-time` facts: campaign finding M7 (`docs/research/raw/2026-10-10-e2e-langfuse-3.80.0.md` line 48: Langfuse 400 for page 0 and -1 and for a malformed timestamp); recorded in `docs/research/langfuse.md` section 1.4. Not re-checked with the `langfuse-docs` MCP (the tool was not loaded in this run).
- Hidden-character set: the catalog's own `hidden` predicate (control, Cf, tag block, variation selectors, default-ignorables), which mirrors `sanitize.Text` (catalog may not import sanitize). Pinned to the sanitizer over every code point by `TestAPathParameterRefusesExactlyTheCharactersTheSanitizerStrips`; tab, line feed and carriage return are refused in a path parameter although the sanitizer keeps them in a payload.
- Query values: tab, line feed and carriage return are refused too, except in a parameter called `filter` (a JSON text, pretty-printed it holds them). First draft exempted them in every query value; the Spec reviewer found that broader than the ticket (story 42: consistent with a path parameter), so it was narrowed. The exemption is by parameter name (`Param.holdsJSONText`), not by schema: the catalog has no marker for "JSON text".
- Metrics `query`: checked on the decoded strings and keys inside `metricsQuery`, after the structural checks, not on the raw string. A malformed query keeps its metrics-specific message and hint; a JSON escape cannot smuggle a hidden character. This reverses an existing test on purpose: `TestInstructionsHiddenCharactersAndMarkupInAMetricsFilterReachLangfuseAsInertData` asserted that a hidden character in a metrics filter value reached Langfuse; it is now `TestInstructionsAndMarkupInAMetricsFilterReachLangfuseAsInertData` (instructions and markup only), and the hidden-character cases refuse.
- `TestTheConfirmationShowsAnInjectedPathParameterStripped` could not stay: a path parameter with a hidden character no longer reaches the confirmation. It is now `TestTheConfirmationShowsAPathParameterWithMarkupAsText`, and the refusal-before-asking case went into `TestADestructiveCallWithBadArgumentsIsRefusedBeforeTheUserIsAsked`.
- RFC 3339 is checked with a strict shape regexp plus `time.Parse`: `time.Parse(time.RFC3339, ...)` alone takes a one-digit hour and a comma before the fraction (found by the Spec reviewer with a scratch run). A lowercase `t`/`z` and a leap second (`:60`) are refused too; Langfuse's own parser does not take them either.
- The existing length-bound fuzz `FuzzRequestEnforcesALengthBoundWithoutRepeatingTheValue` has a seed with hidden characters; it now accepts the hidden-text refusal as the outcome for an in-bounds value that holds one.

## Learnings
- The Write, Edit and Bash tools expand a backslash-u escape in typed source into the real character (a Go file then fails with "illegal byte order mark" or trips gosec/staticcheck); build hidden characters from code points (`string(rune(0x200b))`), write escapes as `"\\" + "u200b"` or in a Python script with `chr(92)`, and run `grep -nP '[^\x00-\x7F]'` on the file afterwards. Applies to issue bodies too.
- `time.Parse(time.RFC3339, v)` accepts a one-digit hour and a comma before the fraction; pair it with a shape regexp when the contract is RFC 3339.
- `gofmt` is not on the bash PATH; run `$(go env GOROOT)/bin/gofmt`.
- A test that looks for a hidden rune in the audit log must skip line feed: the JSON log lines end with one.
- `ticket-reviewer` agents return findings as a message to the caller, not as the final text; ask with SendMessage if they run long.
