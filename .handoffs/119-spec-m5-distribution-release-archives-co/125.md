## Learnings
- `npm` under `~/.local` is broken on this machine; use the Node 24.21.0 tarball in the scratchpad.
- `claude mcp add`: an option must sit between the last `--env` and the server name.
- A Gemini CLI project `settings.json` is read only in a trusted folder (`~/.gemini/trustedFolders.json`).
- Ollama qwen3:8b cannot load its KV cache while the Langfuse stack runs (RTX 3060 OOM).
- `codex exec` waits on stdin; redirect `< /dev/null`.
