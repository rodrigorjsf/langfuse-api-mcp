## Decisions & deviations
- New optional S2 variable `LANGFUSE_MCP_SMOKE_CA_DIR` (deviation from "parameterized only by the launch command"): the container needs the CA file at a path it can mount; the dir is mounted read-only at the same path so `LANGFUSE_CA_CERT` is identical inside. CA file written 0644 (public cert; the image's non-root user must read it).
- `-e NAME` forwarding (no values in argv) so the negative case simply leaves `LANGFUSE_CA_CERT` empty.
- The untrusted-CA case runs for every S2 channel and S1, not only the container (stronger, cross-OS classification already proven by server tests).
- #28 expected `"roots":"bundled-fallback"`: wrong premise — distroless static ships a CA bundle and sets `SSL_CERT_FILE` to it, so the server logs it as an ambient source. The smoke asserts the mounted file is an explicit source with 1 certificate (contains-check, not exact list).
- Image SBOM scanned from the amd64 image only (AC says one SBOM); README says so.
- Snapshot images are per-arch tags; the multi-arch manifest exists only on push (#126). README states it.
- Local verification: Docker Desktop's host network is its VM, so the smoke was run from a `docker:29-cli` container on `--network host` with the host Go toolchain mounted (mirrors the runner).
