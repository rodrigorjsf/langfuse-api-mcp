## Decisions & deviations
- **3.225.11 serves the legacy family only**, not "legacy plus experiments" as ADR-0012 and the catalog fixture say. It was observed live: `/experiments` answers 404 "only available in a Langfuse v4 write mode". The pin follows runtime, and the research doc records it. Correcting the ADR and the fixture is #84.
- **No seeding in the check.** Reachability is proven with placeholder IDs. A JSON "not found" means the route is served; an HTML 404 or a write-mode 404 means it is not (research §2). So no OTLP/protobuf seeder was written.
- **The payload-query probe is skipped on 3.80.0, 3.225.11 and 4.46.0-dual in the weekly matrix.**
  - On 3.x it needs `/v2/observations` and OTLP/JSON seeding, which that version does not support correctly.
  - On a local dual stack it saw 0 of 66 seeded rows in 3 minutes.
  - Tracked in #85.
- The detection budget in the live check is 30 s, not 5 s (a freshly started stack can be slow). The client rate limit is 1000/min, the executable's self-hosted default.
- `workflow_dispatch` no longer runs the PR `self-hosted` job. It runs the pinned matrix and Cloud instead, which avoids running `events_only` twice.
- `sleepCtx` moved to the default build (`readlive_test.go`). `liveSession` was split into `liveSession` and `liveClient`. `startCatalog` was extracted from `startServer`.

## Learnings
- Langfuse 3.225.11 gates `/experiments` behind a v4 write mode; it is legacy-only.
- `langfuse.New` with no RateLimit defaults to 30/min. Set RateLimit in tests that call many operations.
- To run a second Langfuse stack locally, remap the compose ports with sed. The `langfuse-mcp-it` stack on :3000 may belong to others, so leave it running.
