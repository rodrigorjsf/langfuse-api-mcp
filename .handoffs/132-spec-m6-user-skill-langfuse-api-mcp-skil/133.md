## What was built
- The server behaviour was already in the base: ticket #114 (wave 1, commits `ce6a26f` and `bbd9fe4`) shipped exactly this change. A no-match query that is not about traces returns the tags and the search-again text with no hint. A query holding `trace`/`traces` keeps the hint, with or without matches.
- This ticket reran the live eval, recorded it, and investigated the remaining failure. It also finished the docs: the security rule and README "Security model" now say when the hint is given, and ROADMAP M6 and `docs/research/INDEX.md` were updated.
- New evidence: `docs/research/raw/2026-09-28-small-model-eval-intent-08-filter-parameter.md`.
