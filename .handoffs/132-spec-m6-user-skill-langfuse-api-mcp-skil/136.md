## What was built
The user skill has two more references, and the entry file `skills/langfuse-api-mcp/SKILL.md` cites both.

- `references/cost-latency.md` finds a cost or latency spike:
  1. Read the query format with `describe_operation metrics_metrics`.
  2. Run one `metrics_metrics` query over a bounded window: the sum of `totalCost`, or a latency percentile, per hour or day, grouped by model or observation name.
  3. List the observations of the spike bucket with `observations_getMany`, with `fields` set to `core,basic,usage,model,metrics`.
  4. Open a suspicious trace with `get_trace_tree`.

  It also covers the ms/s unit trap and the Metrics v2 daily budget: send one query and reuse its result.
- `references/experiments.md`:
  1. `datasets_get` turns the dataset name into its ID.
  2. `experiments_list` takes the ID and a `fromStartTime`, which is required.
  3. `experiments_listItems` is called with `fields` set to `io,scores`.
  4. The items are joined on the dataset item, and their scores and outputs are compared.
  5. `get_trace_tree` opens the trace of a regressed item.

## Decisions & deviations
- **`fields` groups.** The references name the `fields` groups explicitly. Both reviewers found that without them the rows lack cost, model, latency, outputs and scores. The catalog's `fields` parameter has no description, so `describe_operation` cannot supply them. This goes past "stable surface only", in the same way `traces.md` names `isRootObservation`.
- **Fixtures renamed.** In `scripts/test_check_skill.py`, two fixtures cited `references/cost-latency.md` and `references/prompts.md` as missing files. The first now exists, and the second will once the prompts ticket lands. Both now use `references/no-such-billing.md`. A sibling ticket may make the same edit, so this can cause a merge conflict; resolve it to either name that never exists.
- **v3 fallback dropped.** The experiments reference sends no v3 dataset-run fallback, because the spec covers v4 flows only. `operation_unavailable` is handled by the rule in the entry file.
- **ROADMAP.md.** The M6 row and the #98/#134 note are updated for the two new references. Other wave tickets edit the same lines, so a conflict is likely; merge by listing every reference.
