## Learnings
- `claude -p` declines an unanswered MCP elicitation. Use interactive tmux (Enter on Accept) for confirmation proofs.
- Python eval output is block-buffered to files. Results appear only at exit; do not poll mid-run.
- A v4 `events_only` experiment is seeded via OTel `langfuse.experiment.*` attributes, not `/dataset-run-items`.
