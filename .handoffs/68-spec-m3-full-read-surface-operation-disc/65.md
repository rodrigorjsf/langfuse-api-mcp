## What was built
- `search_operations` returns the operation index: `operationId — first description line`, grouped by OpenAPI tag, as text plus `structuredContent` under an `outputSchema`. Optional `query` = AND of case-insensitive substrings over ID, tag, description line. No match is a normal result naming the tags; the query is never echoed.
- `describe_operation(operationId)` returns the operation description: tag, line, method, tool, and every parameter with location, type, format, required, repeated, enum, bounds, default.
- Write operations are hidden unless write mode (`server.WithWriteMode()`); in write mode each index line names its tool.
- `execute_read`: description and `operation_not_found` hint name `search_operations` (#36); every parameter refusal hint lists the valid parameter names and names `describe_operation`; the limit refusal no longer echoes the value.
- Neither discovery tool calls Langfuse (tests run with a nil client).

## Decisions & deviations
- #65 is an umbrella over #69 + #70; with no context handoffs and base = main, this branch implements both fully. Expect overlap with the parallel #36 branch (same `execute_read` description/hint lines in `internal/server/server.go`) and possibly #34 (`server.New` signature): the integrator should keep this branch's hint text.
- Write mode: new variadic `server.Option` / `server.WithWriteMode()`; `cmd` does not wire it (LANGFUSE_MCP_ALLOW_WRITES is M4). Index then names `execute_write`, which is not registered until M4.
- Query/operationId with control (incl. tab/newline) or invisible chars are refused (per #69/#68), not stripped; ADR-0002 amendment wording updated to match.
- Embedded spec has no parameter bounds; catalog parses them when present and sets list `limit` to 1..100 default 50 itself. Spec bounds are described, not enforced (follow-up #80).
- Description line = full first line as specified; legacy lines are whole deprecation notices (~10 KB index, follow-up #79).
- Parameter descriptions from the spec are not included in `describe_operation` (not asked).
- Test-only direct dependency `github.com/google/jsonschema-go` (already in module graph via go-sdk; go.mod moved from indirect) to validate structuredContent against outputSchema; justified in `.claude/rules/go.md`.
- Rule text updated: `.claude/rules/mcp-tool-design.md` (point at discovery tools, not the external reference), `security.md` (discovery controls), `go.md`.
