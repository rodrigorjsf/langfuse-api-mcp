## What was built
- `scripts/gen-union-catalog.py` converts every kept write body schema from the OpenAPI 3.0 dialect to JSON Schema 2020-12 (`to_2020_12`, called via `body_2020_12` in `build` on the body the catalog keeps).
- `nullable: true` on a single-typed schema becomes `type: [T, "null"]` (and `null` is appended to `enum`). A schema with a const, `not` or a combinator, or with no single type, becomes `{title/description, anyOf: [rest, {type: null}]}`. An unconstrained schema only loses the keyword.
- Boolean `exclusiveMinimum`/`exclusiveMaximum`: `true` moves `minimum`/`maximum` into the numeric form, and `false` is dropped. `true` with no bound stops generation.
- `discriminator`, `example`, `xml` and `externalDocs` have no conversion. If one appears in a kept body, generation stops and names the operation.
- The embedded catalog is regenerated from the real release tags v3.0.0–v4.46.0. The operation set is the same and only the request bodies changed: body `nullable` went from 466 to 0, and the file is 494,316 bytes (budget 1 MiB).
- No tool behaviour changes, because nothing reads `RequestBody.Schema` yet.

## Decisions & deviations
- The conversion runs in `build` on the one body kept per operation, not in `operations()` for every spec. Converting every release's body stopped generation on an `example` in an old `ingestion_batch` spec whose body the catalog discards.
- A nullable enum gets `null` appended. Without it, 2020-12 would refuse null even though the type allows it.
- A nullable schema that has a combinator is wrapped in `anyOf` with null rather than getting a type union, because the combinator would still refuse null.
- Unconverted 3.0 keywords stop generation (fail closed) instead of being dropped silently. The survey of v3.0.0–v4.46.0 bodies found only `nullable`.
- Parameter schemas keep `nullable`, which is out of scope. The catalog's parameter validator reads it (`Schema.Nullable`).
- The compile test uses a floor of 35 bodies instead of the current 39. #110's four exclusions each remove a body, so the test stays green whichever branch merges first.
- No advisor/rubber-duck pass, per the implementer rules.

## Learnings
- jsonschema-go puts unknown keywords in `Schema.Extra` and compiles them silently; check `Extra` to prove the dialect.
- The union catalog generator needs about 2 minutes of network for a fresh clone; `--repo` into the scratchpad works.
