## What was built
`scripts/small-model-eval.py` is a standard-library Python script. It builds the server, or takes `--server BIN`, and starts it over stdio against a fake Langfuse on 127.0.0.1. The fake answers as 4.46.0 `events_only`: the health version, the v4 read and experiments sentinels on, the legacy family returning 404, and an empty page for every read.

The script sends 11 natural-language intents to `claude-haiku-4-5` through the Messages API (temperature 0, at most 8 turns each). The model gets only the server's four tools: `search_operations`, `describe_operation`, `execute_read` and `get_trace_tree`. An intent passes when the model makes the expected call (tool, operationId, key parameters) and the server accepts that call. The script prints PASS/FAIL per intent, with the calls the model made, then `TOTAL n/11 passed`. Exit code: 0 when every intent passes, 1 when any fails, 2 on a setup error.

## Decisions & deviations
- **Fake Langfuse instead of a test project.** The ticket allows either. The fake keeps the run hermetic and free of keys. The eval judges which operation the model reaches, not the data it gets back.
- **Profile: 4.46.0 `events_only`.** On 4.46.0, `metrics_daily` (removed in 3.62.0) and `score_get` (removed in 3.53.0) are absent, and so are the legacy trace reads. The metrics intent therefore expects `metrics_metrics`, with a query-JSON check: view `observations`, measure `totalCost`, a filter `traceName = checkout`, and granularity `day`.
- **11 intents, not 10.** The ticket says "about 10".
- **Pass means the model made the expected call and the server did not return `isError`.** The model's later turns are not judged.
- **Additions:** `ANTHROPIC_BASE_URL` (https, or http on loopback only), `--model`, `--max-turns` and `--server`. The base URL is what makes the smoke test possible.
- **This PR must not auto-close the run criterion.** If the PR body says `Closes #75`, #88 still carries the recorded run.
