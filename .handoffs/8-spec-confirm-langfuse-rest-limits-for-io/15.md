## Decisions & deviations
- This is a characterization test, so there is no red phase for upstream behaviour. The assertions encode the observed outcome, and an upstream guard added later would fail the weekly Cloud run.
- The Cloud run was executed locally with `.env.integration`, because scheduled/dispatch workflows cannot run before merge (#40).
- Self-hosted keys were recovered from the running `langfuse-mcp-it` container env; no env file existed.
- The poll uses `fields=core,basic`: on Cloud, `fields=core` rows come back without `name`.
- The limit 50/51 probes carry no `name` or `environment` filter, per the coordinator's constraint. They check that the `input` key is present (not non-null) so that foreign rows cannot break them.
- Added a goleak ignore for the HTTP/2 `ClientConn.readLoop` in live runs. Without it the Cloud leg fails at package end, even for the health test alone. Evidence posted on #41 and #40.
- `langfuseDirect` uses its own transport with system roots only. A private-CA self-hosted instance would fail at seeding; this is documented in a comment.
