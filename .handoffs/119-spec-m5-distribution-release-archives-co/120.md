- Workflow triggers: no `workflow_dispatch` and no tag trigger (tag-only steps belong to #126). Path filter follows the spec literally (`packaging/**`, `cmd/langfuse-mcp/**`, go.mod/go.sum, the workflow); `internal/**` changes are covered on main push and weekly.

- Windows extraction uses pwsh `Expand-Archive`; checksum via `awk` line + `sha256sum`/`shasum -a 256`.
