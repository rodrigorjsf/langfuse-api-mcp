## Decisions & deviations
- **Link form.** A README link must be a `/issues/N` URL. A bare `#N` does not count, because GitHub does not autolink it in a repository file. The mapping rule still accepts `#N`.
- **Code spans.** The word inside a code span is a quotation, not a mark. This lets the rule's own description quote `Planned` without linking an issue that will close.
- **Line granularity**, as the spec says. A line passes when it holds any issue URL. The config-file line already linked #29 and #45, but its marks were still linked to #160 by hand.
- **CLI.** It is now `check-docs.py [MAPPING_FILE [README_FILE]]`. With no arguments it checks both files.
- **The heading "Verify what you run **(Planned, #150)**".** Its anchor changed to `#verify-what-you-run-planned-150`, and the 2 internal links were updated.
- **The status banner (line 6)** links #150 so its generic "Sections marked **Planned**" sentence passes.
