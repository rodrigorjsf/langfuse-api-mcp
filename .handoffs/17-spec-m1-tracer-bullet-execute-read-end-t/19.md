## What was built
- `execute_read` checks every call before anything is sent to Langfuse. The operation's OpenAPI parameter schema decides what is valid. Unknown parameters, missing required parameters, wrong types, integers with a fraction, and values outside an enum all return `invalid_argument`. The message names the parameter and the reason, e.g. `parameter limit: want an integer, got a string`.
- The top-level arguments get the same treatment: a missing or non-string `operationId`, `parameters` that is not an object, or an unknown argument (e.g. `url`). The message never leaks Go types.
- A write operation returns `invalid_argument` ("... runs read (GET) operations only"). An unknown ID returns `operation_not_found`. An excluded ID (ADR-0004) also returns `operation_not_found`, with its own "not exposed by this server" message and hint.
- A path parameter is refused when it is empty or holds `/`, `\`, `.`/`..`, an `http(s):` prefix, or a control character. Accepted values are percent-encoded into one path segment.
- The Langfuse client never follows a redirect that changes scheme, host or port. Such a redirect returns the new tool error `redirect_refused`. Same-origin redirects are followed, with Basic auth kept.
- At startup, `LANGFUSE_BASE_URL` must be `https`. Plain `http` is accepted only for `localhost` or a loopback IP; anything else exits 1 naming the variable.

## Decisions & deviations
- **New error code `redirect_refused`.** The ticket names no code. The new code is additive under ADR-0008 and is documented in `.claude/rules/errors.md` and the README. It is not retryable, and its hint tells the user to point `LANGFUSE_BASE_URL` at the redirect target.
- **Scheme refusal covers only `http:`/`https:`.** Other `name:` prefixes pass, because IDs such as `user:42` are legitimate. After the `/` refusal and percent-encoding, a scheme cannot name a host. "A host" is covered by the `//` / `/` refusal.
- **`/` refused per the ticket, even though Langfuse folder names (prompts, datasets) need an encoded `/`.** Filed as #33.
- **`.` refused too.** The fuzzer found that `/sessions/.` normalizes to the list endpoint.
- **Parameter validation details:**
  - A `$ref` enum component is resolved at `catalog.Load`. A non-scalar ref fails loudly.
  - JSON null omits a nullable parameter.
  - A single scalar for an array parameter counts as a list of one.
  - Integers are bounded to ±2^53.
  - `format: date-time` is not validated; Langfuse answers 400, which is #20's `langfuse_bad_request`.
  - Negative integers are not refused; limit clamping is #22.
- **Loopback means literal `localhost` or a loopback IP (netip).** Other names that resolve to loopback do not count.
- **Plain http to a non-loopback host now fails startup.** Docker-network self-hosted setups on `http://langfuse-web:3000` must use TLS or a loopback port mapping (README updated).
- **The go-sdk low-level `AddTool` does not validate against the input schema.** `decodeExecuteReadInput` is the validation.
