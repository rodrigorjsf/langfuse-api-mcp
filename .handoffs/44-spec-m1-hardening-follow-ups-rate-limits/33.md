## What was built
- `execute_read` now reads prompts and datasets that live in folders. It accepts a Folder name such as `support/triage/system` on exactly four path parameters: `prompts_get`/`promptName`, and `datasetName` of `datasets_get`, `datasets_getRuns` and `datasets_getRun`. Every `/` is sent as `%2F`, so `GET /api/public/v2/prompts/folder%2Fsub%2Fname`.
- The allow-list is static and fails closed. Every other path parameter still refuses `/`, including `runName` and every ID.
- A Folder name is refused with `invalid_argument` if it has a leading or trailing `/`, `//`, `\`, a `.` or `..` segment, a control character or an `http(s):` scheme.
- `.`/`..` are now checked per segment on every path parameter, so `v1..2` is accepted everywhere.
- Refusal messages name the parameter and the rule, never the value.
- A 404 or 400 answering a Folder-name call carries a static hint. It covers a proxy that decodes `%2F` (langfuse/langfuse#12720), the `prompts_list` `name` workaround and the upstream dataset-runs bug (langfuse/langfuse#13933).

## Decisions & deviations
- The allow-list is `internal/catalog/folder.go` (`folderCapable`, keyed by `folderParam{operationID, param}`). It follows the pattern of `excluded` and `metricsOperations`.
- New exported field `catalog.Request.FolderName`. It is set when an accepted path value contains `/`, which is only possible on allow-listed parameters. The server uses it to choose the hint.
- The hint replaces the generic `langfuse_not_found`/`langfuse_bad_request` hint. For `operation_unavailable` (an HTML 404, which is what a `%2F`-decoding proxy produces) the hint is appended after the version/family hint, so ADR-0012 information is kept.
- The existing validation case `trace..1` was removed from the refusal list, as the brief intends: per-segment `..` for every path parameter.
- `\` now has its own message, split from the `/` one.
- The integration dataset cannot be deleted, because the public API has no dataset delete. It stays under a run-unique name.
- No ADR, per the brief.
