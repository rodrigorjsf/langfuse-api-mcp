## Decisions & deviations
- Added a second live test (`projects_get`) because health alone does not prove the key pair authenticates.
- Self-hosted startup lives in `scripts/` (not inline YAML) so CI and local runs are the same procedure.
- `.golangci.yml` gains `run.build-tags: [integration]` so the suite is linted; consequence: `leak_default_test.go` (`!integration`) is not linted (trivial file).
- goleak: keep-alive goroutines of the live client are ignored only when `LANGFUSE_TEST_BASE_URL` is set (client cannot close idle connections) — #41.
- `readLive` tests run in the default build so they run on 3 OSes with -race.
- Integration jobs use `-race`. Cloud secrets scoped per step via a YAML anchor (GitHub Actions supports anchors).
