# Handoff — #79: Operation index lines of legacy reads are whole deprecation notices

## What was built
Before this change, the index line of every deprecated operation was its ~500-character deprecation notice. Now `search_operations` and `describe_operation` show a short line: what the operation does, plus the operation to prefer. For example, `trace_list — Get list of traces (legacy: prefer observations_getMany when it is available)`, the wording ADR-0012 §5 uses. The union catalog generator writes that line as `x-summary` on each operation whose description opens with `**Deprecated:**`. The catalog uses `x-summary` as `DescriptionLine`, and uses the first line of the description when there is none. Every index line is now also cleaned the same way: a Markdown link keeps only its text, and a line is cut at 200 runes with `…`, on top of the hidden and control character stripping that already existed. The read index without a query dropped from 8,779 to 6,991 bytes.

## Decisions & deviations
- **Budget: the AC's amendment branch.** Reaching 5 KB would mean cutting every non-legacy line to its first sentence, which loses useful text such as "requires organization-scoped API key". The 1.2k figure counted 58 operations of one spec. The union catalog has 68.
- **The summary pass was applied offline to the committed catalog.** `summarize(paths)` reads only the finished `paths`, so I imported the script's function over the committed JSON instead of running a full regeneration. A full regeneration needs a clone of a few hundred MiB and would pull in newer release tags, which would change the fixtures. Running the pass over the base commit's JSON reproduces the committed file byte for byte.
- **Replacement rule.** The replacement is the first `/api/public/...` path in the notice, mapped to the live operation with the same method at that path, or at its only `/{id}` child when the legacy operation is by ID. When no operation matches, the line names the path. When the notice names no path, the line ends in "(legacy)" alone (`datasets_deleteRun`).
- The removed `unstable_*` operations also get "legacy: prefer" lines, because they have the same kind of notice. `datasetRunItems_create` names `opentelemetry_exportTraces`, which ADR-0004 excludes. That is a write-mode line only, and it is what the notice says.
- The 200-rune cap and link stripping apply to all lines, not only legacy ones, under the prompt-injection AC. `security.md` and the README "Security model" are updated to match.
