## What was built
- `LANGFUSE_CA_CERT` (PEM file, may be a bundle) and `LANGFUSE_CA_CERTS_PATH` (directory, non-recursive, regular files only, symlinks followed, non-PEM files ignored) are added to the trust pool at startup.
- The base roots are the OS store; when the OS offers none (no pool or an empty one), the roots bundled from `golang.org/x/crypto/x509roots/fallback/bundle` are used.
- A missing/unreadable/empty/non-PEM file, a damaged certificate, or a missing/empty/no-PEM directory stops startup (exit 1) with one JSON stderr line naming the variable and path.
- On success the executable logs one JSON line `"CA sources loaded"` with `roots` (`os` | `bundled-fallback`) and `sources` (variable, path, kind, certificates), then exits 0 (no client/transport yet).
- TLS config from the pool: `MinVersion` TLS 1.2, no skip-verify.

## Decisions & deviations
- `config.Load(env map[string]string) Config` (no `args`, no error yet): no flags exist; #12 adds the config file and an error return.
- `trust.Sources{Explicit []Source}`, `Source{Variable, Path, Directory}`; `Kind` has only `KindExplicit`. Spec's "origin" and per-source "warning" deferred to #11/#12 (only meaningful for ambient/config-file sources).
- `Pool` wraps `*x509.CertPool`; `Pool.TLSConfig()` returns a fresh `*tls.Config{RootCAs, MinVersion: TLS12}` each call.
- Fallback roots: used the `bundle` subpackage directly, not `import _ ".../fallback"`. Reason: explicit origin in the report, no global side effect. Fallback applies when the system pool is missing OR empty (on Linux `SystemCertPool` returns an empty pool, not an error). The fallback test simulates "no OS roots" in a child process via `SSL_CERT_FILE`+`SSL_CERT_DIR` → Linux only (skipped elsewhere). ADR-0006 amended (not superseded) to record this: it extends, does not contradict, the ADR and the ticket already required it.
- New dependency `golang.org/x/crypto/x509roots/fallback v0.0.0-20260921070245-7a4a4d6beae2` (allowlisted in `.claude/rules/go.md`); go.sum now exists.
- Certificates parsed individually (`pem.Decode` + `ParseCertificate` + `AddCert`) to count per source; non-CERTIFICATE blocks skipped; a damaged CERTIFICATE block in an explicit source is an error.
- `main` → `run(environ, stderr) bool`; exit 1 on startup failure; slog JSON to stderr.
- `gosec` G304 suppressed on the CA `os.ReadFile` with justification (operator-provided paths).
- ROADMAP unchanged: M2 not finished.

## Learnings
