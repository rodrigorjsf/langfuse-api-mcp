# v0.2.0 post-release proofs (2026-10-15, #186)

Ticket #186 (spec #172): every "signed" and "installable" claim of `v0.2.0` was checked against the published artifacts,
from a machine outside CI, in the form of [the v0.1.0 record](2026-09-30-v0.1.0-release-proofs.md).

## Setup

- **Date:** 2026-10-15 (UTC). Log timestamps marked `-03:00` are the machine's local time.
- **Machine:** the maintainer's WSL2 Linux x86_64, Go 1.27.2, Docker daemon available.
- **Release:** GitHub Release `v0.2.0`, published 2026-10-15T00:49:05Z, 25 assets.
  - Release run: https://github.com/rodrigorjsf/langfuse-api-mcp/actions/runs/38661158277, conclusion `success` on attempt 3.
  - Commit: `8c804b5a60d09fb5a6fbb5652e3991cebe850635`, the tag's commit and the merge of #229.
  - Every job of the run passed: `snapshot`, the archive, `.mcpb`, `npx` and container smokes on every runner, `sign-blobs`, `publish-image`, `publish-npm`, `github-release`, `publish-registry`.
- **How the proofs ran:** stages 9 and 10 of `scripts/release-wizard.sh 0.2.0` ran the checks and wrote their transcript, and an agent session ran the remaining checks.
  - Wizard (checksums, cosign on the blobs and the image, the Registry entry): run by the maintainer.
  - Agent (GitHub attestations, `go install`, `npx`, `npm audit signatures`, the image under `docker run`): done because two of the wizard's checks left no usable output.
    - `gh attestation verify` printed nothing in the non-interactive transcript, as with `v0.1.0`.
    - The machine's own npm is broken (`Cannot find module '/home/rodrigo/.local/lib/node_modules/npm/bin/npm-cli.js'`), so npm ran in a `node:22.11.0` container (npm 10.9.0).
- **Verifiers:**
  - cosign v2.6.5.
  - GitHub CLI 2.102.0 (`go install github.com/cli/cli/v2/cmd/gh@latest`). The system `gh` 2.45.0 has no `gh attestation`.
- **Assets:** downloaded with `gh release download v0.2.0 -R rodrigorjsf/langfuse-api-mcp`. They are:
  - 6 archives and their 6 SBOMs;
  - `checksums.txt`;
  - the `.mcpb` and the skill ZIP;
  - 9 `.sigstore.json` bundles;
  - the image SBOM.
