This run checked each criterion against the base with fresh test runs and records the proof. An agent calls
`describe_operation(operationId)` and gets the operation description as text plus `structuredContent`:
tag, description line, method, the tool that runs it, and every parameter with its location, type, format,

lists the operation's valid parameter names and names `describe_operation`, and never echoes the value.
