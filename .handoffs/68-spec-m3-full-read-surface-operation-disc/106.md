## Decisions & deviations
- The wording shows the example without backslashes (brief allowed "an equivalent that shows the string once"): hints reach the model inside JSON tool errors, so a backslash literal would itself appear double-escaped.
- First wording ("…with its quotes escaped once, as in any JSON string, never twice") stopped the object/string alternation but the model kept over-escaping: FAIL (recorded in the raw doc). Changed to "the value itself has no backslash before its quotes": PASS.
- Every non-string type of a metrics `query` (not only object) gets the metrics query hint; tested for object, list, number.
