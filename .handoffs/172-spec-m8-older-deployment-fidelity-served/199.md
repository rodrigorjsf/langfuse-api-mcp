Messages are unchanged.
- The `describe_operation` tool description gains one declarative sentence naming `scannedFilters`.

## Learnings
- `go` is not on PATH in this checkout: `export GOROOT=$HOME/go/pkg/mod/golang.org/toolchain@v0.0.1-go1.27.1.linux-amd64 PATH=$GOROOT/bin:$PATH GOTOOLCHAIN=local`.
- `go test -race ./internal/server` in 16 chunks: `go test -race -c`, `server.test -test.list`, `split -n l/16`, then `-test.run '^(a|b|...)$'` per chunk.
- Subtests with `t.Parallel()` start after the parent returns: a check after the loop (`assertNoRequest`, `len(seen)`) is vacuous. Keep such subtests sequential.
- A python `str.replace` mutation that does not match changes nothing: assert the pattern is present before reading the test result.
- `hintOf` already names a helper in `discovery_test.go`; check `grep -rn "func name" internal/server/*_test.go` before adding test helpers to the shared `server_test` package.
