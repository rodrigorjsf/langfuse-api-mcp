## What was built
Under an intent that fails, `scripts/small-model-eval.py` now prints an `answer:` line between `ended:` and `said:` (order: `ended`, `answer`, `said`, `want`) with the server's answer to the last call it sent. `answer (error):` when the server answered with a tool error, `answer:` when it accepted a call that did not match. The text is the tool result's text content, cleaned exactly as the final text is (one line, control and format characters removed, whitespace of any kind becomes one space), then cut to 1000 characters with `...`; `(no text)` when there is none. It covers a conversation that ends on a model turn with no tool call and one that ends at the turn limit. A passing intent, an intent that ends at its forbidden call (intents 12 and 13, never sent) and an intent that made no call print no such line. The model still receives the answer as the server gave it, uncleaned and uncut. No new argument or environment variable; verdicts, matchers, call lines and the `said:` line are unchanged.

## Decisions & deviations
- `run_intent` returns a 5-tuple `(passed, calls, ended, said, answer)`; `answer` is the raw tool result dict of the last sent call, formatted at the print site by `answer_line(result)`. The #182 tests unpack with `ok, *_`, so they run unedited.
- Shared helpers: `one_line(raw, limit)` is the #182 cleaning, now parameterised by the cut; `final_text` calls it with 500, `answer_line` with `ANSWER_LIMIT = 1000`; `result_text(result)` builds the text the model receives and the line prints, so the two cannot drift.
- `answer` is `None` at the expected call that passes, at a forbidden call and when no call was sent. A passing forbid-intent returns its last answer, but `main()` prints only when `not ok`.
- Whitespace: the cleaning uses `str.isspace()` and `split()`, so any whitespace and runs of it become one space. The new docs say that (the ticket's "whitespace controls" was narrower than the code); the #182 caveat (variation selectors and similar marks are not removed) is inherited by reference ("with the same limits").
- The dev doc's sentence on intent 11 ("the server's answers to the refused calls are not printed, #198") was updated: that run did not print them, the line now does, the cause stays a hypothesis until a later run. The record under `docs/research/raw/` is untouched.
