## What was built
The Observations v2 cursor is now documented and proven live. It is base64 JSON of a keyset position, holds no page size, and needs the filters repeated. So `get_trace_tree`'s limit-1000 cursor continues correctly through `execute_read` at a limit of at most 100. Spec #68 story 37's "without gaps or repeats" holds. No production behaviour changed; only the `traceTreeMoreHint` code comment changed. Option 3 (changing `get_trace_tree`) was not needed, because the live check agreed with the docs. New unit tests pin the security properties of the cursor. It is opaque: it is handed back only inside the envelope, never in a hint or the audit line, and sent back unchanged. A non-string cursor is refused.

## Decisions & deviations
- **TDD cadence.** Every new test covers behaviour that already existed (Langfuse's, or the server's). Each passed on its first run, so I checked each one by mutation:
  - Dropping the cursor on continuation fails the live test ("read twice").
  - Stripping `==` from query values fails the pass-through test.
  - Altering `data.meta.cursor` fails the envelope test.
- **Seeding.** The seed is one trace of 5 spans over OTLP/JSON. The second and third newest spans share a start time, so the first cursor falls inside a sort-key tie (review fix SP1).
- **Not parallel.** The live test does not call `t.Parallel()`, so its polling and paging never overlap the payload-query probe on Cloud Hobby's 30 req/min (review fix S1).
- **Skip list.** `integration.yml` adds the test to the skip list for 3.80.0, 3.225.11 and 4.46.0-dual, like the payload probe. The reasons are the same: it seeds over OTLP/JSON and reads `/v2/observations` (#85). It runs on PR self-hosted, weekly `events_only` and Cloud.
- **Shared helper.** The `exportOTLPSpans` helper was extracted into `iowindow_integration_test.go` and is shared by both probes (review fix S2).
- **Docs updated.** Each got a short statement of the new fact or tested control:
  - `docs/research/langfuse.md` §1.4
  - README (the get_trace_tree row and Security model)
  - `.claude/rules/security.md`
  - `.claude/rules/langfuse-api.md` (the Pagination bullet)
  - ROADMAP M3 progress
- **Stack used.** The self-hosted stack was already running (`langfuse-mcp-it-*` containers, 4.46.0 `events_only`). I did not restart or stop it. I took its keys from `docker inspect` and put them in an env file in the session scratchpad, outside the repo.
