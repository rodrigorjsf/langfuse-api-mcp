## Decisions & deviations
- **The built-in `/security-review` could not run over the whole codebase.** It is diff-only: it runs `git diff origin/HEAD...` and failed with `ambiguous argument 'origin/HEAD...'`. I applied its method instead: only concrete issues with confidence over 80%, each with file:line, an exploit scenario and a fix. Five parallel, read-only area reviewers covered startup, the Langfuse client, catalog and sanitize, the MCP surface, and the supply chain. The record is a synthesis of their reports and says so. **The maintainer should accept this reading of "runs `/security-review`".**
- **F1 fix location.** The URL is dropped in `langfuse.Client.send` (`withoutURL`), the only `httpClient.Do` call, so every executor and workflow request is covered. The method and the wrapped cause are kept, so the failure classes still match. The existing network, timeout and redirect tests stay green.
- **F3 scope.** The fix adds `unicode.Variation_Selector` and `unicode.Other_Default_Ignorable_Code_Point` to both `hidden()` copies. The catalog copy has to stay separate, because `catalog` imports nothing internal. Cost: an emoji loses its VS16 selector.
- **Record date.** The record is dated 2026-09-29 (UTC), which is `date -u` at the time of writing.
- **Rule edits.** `.claude/rules/security.md` gained the #156 wording on the Credentials, Tool results and Audit lines, and the HTTP transport line is marked Planned (#160), as `docs-sync.md` requires.

## Learnings
- The built-in `/security-review` is diff-only (`git diff origin/HEAD...`) and fails in a worktree without `origin/HEAD`. For a whole-codebase review, run parallel area reviewers with its method.
- `gofmt` is not on the bash PATH; use `go fmt ./pkg/`.
