## Learnings
- Raw GitHub fetches: curl needs `-g` for paths with `[traceId]`; `gh api repos/langfuse/langfuse/git/trees/<tag>?recursive=1 --jq '.tree[].path'` lists a tag's files; `git clone --depth 1 --branch <tag> --filter=blob:none --sparse` + `git sparse-checkout set <dirs>` reads source cheaply.
- `searchLangfuseDocs` results exceed the tool limit and land in a file; parse the JSON with Python (`d['content'][i]['source']['content'][0]['text']`).
- A foreground `until grep -q DONE log; do sleep 5; done` with a long `timeout` waits for a background chunk run (a bare `sleep` is blocked).
