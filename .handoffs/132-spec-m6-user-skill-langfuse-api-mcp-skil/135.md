## Decisions & deviations
- **#99 no longer reproduces without the skill** at the current server: 4/4 passes, against 0/2 on 2026-09-27. The change that moved the model was not bisected, and the record says so. With the skill the first call is already correct, one call instead of two. #99 closes on the skill plus that drift.
- **Metrics score view names are not listed.** The reference says to pick the view by data type from `describe_operation metrics_metrics`, which names them. This is the stable-surface rule.
- **Some Langfuse semantics are named** because `describe_operation` cannot give them: the catalog has no parameter descriptions for `scoresV3_getManyV3`. They are:
  - comma lists, OR within a filter and AND across filters;
  - `traceId`/`sessionId`/`experimentId` are mutually exclusive;
  - no `userId` on scores.

  Each one is sourced in `docs/research/langfuse.md` (lines ~124-127, §4.4) and was verified with the `langfuse-docs` MCP.
